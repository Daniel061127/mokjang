# 오늘의 말씀 - Daily Devotional App

사용자가 버튼을 누르면 자동으로 오늘의 성경 말씀을 보여주는 웹 애플리케이션입니다. TypeScript와 순수 HTML/CSS/JavaScript로 만들어졌으며, 매일 다른 성경 구절을 표시합니다.

## 주요 특징

- 💬 **성경 구절 기반**: 성경의 다양한 책에서 영감을 주는 말씀 제공
- 🎯 **버튼 클릭으로 표시**: "오늘의 말씀 보기" 버튼으로 쉽게 접근
- 🔄 **자동 로드**: 페이지 로드 시 자동으로 오늘의 말씀 표시
- 📱 **반응형 디자인**: 모바일과 데스크톱에서 모두 잘 작동
- 🎨 **아름다운 UI**: 영혼을 새롭게 하는 깨끗한 디자인

## 프로젝트 구조

```
daily-devotional-app/
├── src/
│   ├── main.ts                      # 메인 진입점
│   ├── components/

│   ├── services/

├── assets/

├── styles.css                       # 애플리케이션 스타일
├── package.json                     # NPM 패키지 설정

```

## 설치 및 실행

### 1. 의존성 설치
```bash
npm install
```

### 2. 개발 서버 시작
```bash
npm run dev
```
- 브라우저가 자동으로 열리고 `http://127.0.0.1:8080`에서 앱을 확인할 수 있습니다.

### 3. 빌드
```bash
npm run build
```
- TypeScript를 JavaScript로 컴파일하고 `dist/` 폴더에 저장합니다.

### 4. 프로덕션 배포
```bash
npm run start
```
- 빌드 후 웹 서버를 시작합니다.

## 사용 방법

1. 앱을 열면 자동으로 오늘의 말씀이 표시됩니다.
2. "오늘의 말씀 보기" 버튼을 눌러 언제든지 새로운 말씀을 불러올 수 있습니다.
3. 매일 방문할 때마다 다른 성경 구절을 보게 됩니다 (년간 365일 기준).

## 포함된 성경 구절

앱에는 20개의 영감을 주는 성경 구절이 포함되어 있습니다:

- 요한복음 3:16 - 하나님의 사랑
- 빌립보서 4:6-7 - 기도와 평강
- 시편 27:1 - 두려움을 이기는 믿음
- 로마서 8:28 - 모든 일의 선함
- 데살로니가전서 5:16-18 - 기쁨과 감사
- ...그리고 더 많은 구절들

## 기술 스택

- **TypeScript**: 타입 안전성을 위한 언어
- **HTML5**: 구조
- **CSS3**: 스타일 및 반응형 디자인
- **JavaScript (ES2015)**: 런타임 동작
- **http-server**: 로컬 개발 서버

## 확장 기능 아이디어

- 🌐 온라인 성경 API 연동 (Bible API)
- 💾 사용자의 즐겨찾기 저장 기능
- 📧 이메일로 일일 말씀 받기
- 🌍 여러 언어 지원
- 🎵 영감을 주는 배경 음악
- 📅 특정 날짜의 말씀 보기
